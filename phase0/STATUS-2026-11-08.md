# DragonLord status, 2026-11-08 (WSL2 test bench)

All results below are reported evidence from one machine (i7-9750H, RTX 2060, WSL2), not owner-attested. Details and commands: `ANDROID17-WSL-RUNBOOK.md`, `PLAN-INSTANCES-UI.md`.

## What works (verified)

| Item | Result |
|---|---|
| Our QEMU 11.1.3 + KVM boots the Android guest | yes, ~50-70 s warm boot, 4-6 min first boot of a fresh disk |
| Guest version | **Android 17 (SDK 37)**, Cuttlefish build 16644040. Not Android 16 (owner accepted 17) |
| Software graphics (no GPU) | works (SwiftShader) |
| Host GPU graphics | works through Gfxstream, GL on the RTX 2060. **8x to 14x faster than software on a heavy GL test**; light UI scrolling shows no clear difference |
| Two instances at once, also both on the GPU | works; GPU shared (4.7 and 7.1 ms/frame vs 4.1 and 2.9 alone) |
| Root: built-in | `adb root` / `su 0 id` on this userdebug image |
| Root: KernelSU (LKM, no kernel build) | loads, manager says Working, per-app grant/deny works, survives a restart (if synced), no GPU regression |
| Instance manager prototype `tools/dlvm.py` | create/start/stop/status/delete with RAM, CPUs, disk, GPU mode, root on/off, serial, DPI, resolution; settings verified inside the guest |
| Debug tooling | `tools/dlrun.py` (log capture + scanner), `tools/dl-bench.py`, `tools/dl-glbench.py` + `tools/glbench` |

## What does not work yet

1. ~~No internet in the guest~~ **fixed**: `tools/run-cvd-wrapper.sh` fills the modem's empty address settings (mobile network CONNECTED + VALIDATED, DNS and TCP work, ping does not under slirp).
2. **Android 16 image not obtained.** Guessed branch names return 400; the real branch name has to come from the ci.android.com branch box.
3. ~~IMEI fixed~~ **per-instance IMEI works**: `dlvm.py create --imei random|<15 digits>` (UI has an IMEI choice). The tool patches a per-instance copy of Google's modem simulator (string + two code immediates) and the guest reports the new IMEI (verified with `service call iphonesubinfo`). Not covered: the KeyMint attestation record still carries the default IMEI; model/brand not yet customisable.
4. **"Root off" is not really off**: the image is `userdebug` and keeps its own `su`.
5. **Windows**: nothing runs natively yet. Hardware Vulkan exists on your Windows side (RTX 2060, Vulkan 1.4), unlike WSL.
6. ~~GUI installer / instance UI~~ **prototype done**: `python3 phase0/tools/dlui.py` (local web UI on 127.0.0.1, token-protected): first-run wizard, instance list with Start/Stop/Delete. Tested through its API incl. a real boot with GPU + KernelSU; visual look in a browser not yet reviewed by you.
7. Dev shortcuts that are not shippable: Google's prebuilt Rutabaga/Gfxstream libraries with a patched header; licence review (QEMU GPLv2 vs Gfxstream Apache-2.0) still open.

## Run it

```
python3 phase0/tools/dlvm.py create demo --ram 4096 --cpus 4 --disk 8192 --gpu gfxstream --root off
python3 phase0/tools/dlvm.py start demo      # then: adb connect 127.0.0.1:6520
python3 phase0/tools/dlvm.py stop demo       # graceful: sync first
```

Needs the unpacked Android image and host tools in `phase0/.work/cuttlefish/cvd`, the QEMU wrapper in `.work/cuttlefish/qemu-ours/` and our QEMU build (see the runbook). `.work` is untracked.
