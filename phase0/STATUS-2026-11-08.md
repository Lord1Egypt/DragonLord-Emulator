All results below are reported evidence from one machine (i7-9750H, RTX 2060, WSL2), not owner-attested. Details and commands: `ANDROID17-WSL-RUNBOOK.md`, `PLAN-INSTANCES-UI.md`.

| Item | Result |
|---|---|

## What does not work yet

1. **scrcpy** (Screen button) fails with "Server connection failed" on this setup; View replaces it.
2. **"Root off" is not really off**: the image is `userdebug` and keeps its own `su`.
3. **Model/brand** not customisable yet; KeyMint attestation keeps the default IMEI.
4. **Windows standalone edition**: not started. Findings and the recommended engine (AOSP Android Emulator, native WHPX + host GPU) are in `WINDOWS-EDITION-PLAN.md`.
5. Dev shortcuts that are not shippable: Google's prebuilt Rutabaga/Gfxstream libraries with a patched header; licence review (QEMU GPLv2 vs Gfxstream Apache-2.0) still open.

## Decisions taken

- Engine order: WSL2 edition first (done for development use), then a portable Windows edition. Android 17 for release. Web panel for both editions.

## Run it

```
python3 phase0/tools/dlvm.py create demo --ram 4096 --cpus 4 --disk 8192 --gpu gfxstream --root off
python3 phase0/tools/dlvm.py start demo      # then: adb connect 127.0.0.1:6520
python3 phase0/tools/dlvm.py stop demo       # graceful: sync first
```

Needs the unpacked Android image and host tools in `phase0/.work/cuttlefish/cvd`, the QEMU wrapper in `.work/cuttlefish/qemu-ours/` and our QEMU build (see the runbook). `.work` is untracked.
